# 型号与传感器

启动窗口的传感器和工具按钮均作用于当前所选型号。两个原生传感器窗口分别保留，公共 UI 控件和运行环境共用。

| 功能 | 11 NFC | 10 Pro |
| --- | --- | --- |
| 原厂启动、屏幕、鼠标触摸 | 已支持 | 已支持 |
| 电池、温度、充电输入 | 已接入硬件模型 | 已接入硬件模型 |
| 加速度、陀螺仪、磁场、3D 姿态 | 模拟输入与状态 | 模拟输入与状态 |
| PD / LED | 原始输入、活动观察 | 原始输入、活动观察 |
| 环境光 / 原厂亮度 | 已接入 | 独立光感通道，先开启自动亮度 |
| UART RX/TX | UART0/1/2 | UART1/2 |
| 电脑录音输入 | 有录音路由 | 未完成验收 |
| NFC | 实验总线与观察队列 | 未完成验收 |
| GNSS | 无 | AG3335M 坐标、速度、方向、卫星和定位开关 |
| 实时显示旋转 | 无 | 0/90/180/270°，触摸同步 |
| DID / 序列号工具 | 独立工具页 | 独立工具页 |

输入只给参考值，有限数值可自由调整；ADC 超出位宽时按低 16 位传给模型。电量和温度由固件采样、滤波和算法计算，改变硬件输入不保证百分比立即跳变。光学输入不等同于已算出的心率/血氧，磁场方向还受原厂校准影响；未被固件开启的通道可能没有采样。

完整 NFC 射频/eSE 未实现，3D 灯珠和 PD 外观用于显示已实现的逻辑状态。GPU 支持范围有限，不能保证所有应用画面。
